# Codveda Data Science Internship - Project Portfolio

## Overview

This repository contains my comprehensive work completed during my data science internship with Codveda. The internship was structured in three progressive levels, each containing three tasks that built upon foundational data science concepts and advanced to more complex machine learning and deep learning applications.

## Internship Structure

- **Level 1 (Basic)**: Data Collection, Cleaning, and Exploratory Analysis
- **Level 2 (Intermediate)**: Predictive Modeling and Machine Learning
- **Level 3 (Advanced)**: Time Series, NLP, and Neural Networks

---
